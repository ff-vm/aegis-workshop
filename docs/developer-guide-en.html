03

Get set up

By 6:50 PM, run Hello Robot in dry-run on your own laptop. Dry-run sends no real commands, so you can build everything without a robot.

  1. Install Python 3.10

    The SDK wheels are built for Python 3.10 (Linux and Windows). On a Mac, skip this step: Docker provides Python 3.10 for you (next step).

  2. Install the FF SDK

    Use the wheel for your platform from the on-site devkit.

    # Linux laptop (dry-run)
pip install aegis_devkit/wheels/ff_sdk-*-linux_x86_64.whl
# Windows laptop (dry-run)
pip install aegis_devkit/wheels/ff_sdk-*-win_amd64.whl

  3. On a Mac: run the SDK in Docker

    There is no macOS wheel, so on a Mac the SDK runs in a small Linux container. Install and start Docker Desktop, then build the image once from the folder that contains aegis_devkit/. It installs offline from the devkit wheels.

    # Mac (Apple Silicon): build once
docker build --platform linux/arm64 -t ff-sdk -f - aegis_devkit/wheels <<'EOF'
FROM python:3.10-slim
COPY *.whl /tmp/
RUN pip install -q --no-index --find-links /tmp /tmp/ff_sdk-*-linux_aarch64.whl
WORKDIR /w
ENV FF_SDK_DRY_RUN=1
EOF
# Then use ffpy wherever the guide says python
alias ffpy='docker run --rm -it --platform linux/arm64 -v "$PWD":/w ff-sdk python -u'
ffpy hello_robot.py

    Intel Mac: use linux/amd64 and the linux_x86_64 wheel. Docker can't reach the Mac webcam, so for Task 2 run the gesture code (MediaPipe, OpenCV) in a normal Python venv on the Mac. Real robot runs happen at the test stations either way.

  4. Clone the starter repo

    TBD: repo link. It has templates for all three tasks, plus graceful_shutdown.py from the devkit. That script e-stops on Ctrl+C or an exception, and shuts down cleanly (stop → damping → close) on a normal exit. Start every real-robot program from a template. Don't write your own exit logic.

  5. Run Hello Robot in dry-run

    # Dry-run self-check only. For real robots, use a starter-repo template.
import asyncio
import ff_sdk
from ff_sdk import Config

async def main():
    cfg = Config.from_env()
    cfg.dry_run = True                       # dry-run: no real commands
    dog = await ff_sdk.connect("aegis://DEMO", config=cfg)
    try:
        print(dog.diagnose().summary())      # health report
        print("Presets:", dog.motion.known_presets())
        await dog.motion.stand()
        await asyncio.sleep(dog.motion.preset_timeout("stand"))
        await dog.motion.stop()
    finally:
        await dog.close()

asyncio.run(main())
🤖

At a test station: start from the starter-repo template, set cfg.dry_run = False and change the target to aegis://<serial>. The serial number is posted at each station. The health report should say aegis SDK — connected. If it says offline, commands go out but the dog won't move: ask a mentor.

04

Safety rules (must read)

Break any rule and the mentor hits the e-stop. That run scores zero.

0.3m/s

Speed limit

Linear speed at most 0.3 m/s. Turning at most 0.6 rad/s.

1m

Clear zone

Real robots run only at test stations, with a mentor on the e-stop. Nobody within 1 m of the dog.

0.5s

Every move stops itself

cmd_vel holds its speed until the next command or stop(). Loops and remote control need a watchdog: no new command for 0.5 s means stop().

🛑

Use graceful_shutdown.py

Already wired into the starter repo. On Ctrl+C or an exception it calls await dog.e_stop(reason="..."); a normal exit runs stop() → damping() → close().

🔁

After an e-stop

Every command is rejected. Once it is safe, call dog.estop.reset(), then connect again.

🚫

Tricks are off

Only two presets are allowed tonight. No autonomous obstacle avoidance: the dog has no lidar.

shake_hand*lie_downjumpfront_jumptwo_leg_standbackflip

* footed variant only

FF SDK quick reference

Everything the three tasks need. All calls are async, so use await unless the table says otherwise. Based on ff_sdk 0.1.0a10; the on-site devkit docs win if they differ.

CallWhat it doesNotes
ff_sdk.connect(target, config=cfg)Connects and returns dogDry-run: aegis://DEMO. Real robot: aegis://<serial>
Config.from_env()Creates a configcfg.dry_run = True turns on dry-run
dog.diagnose().summary()Health reportReal robot should say aegis SDK — connected
dog.motion.stand()Stand upThe dog must stand before it can walk
dog.motion.cmd_vel(linear=, angular=, lateral=)Forward m/s, turn rad/s, sideways m/sSpeed holds until the next command or stop()
dog.motion.stop()Stop
dog.motion.damping()Relax the motors and lie softCall before you exit
dog.motion.known_presets()Presets this variant supportsNo await

dog.motion.preset_timeout(name)Move duration in secondsNo await. Wait this long before the next command, or the move gets cut off

dog.state.battery()Battery percent (0–1)NaN when unknown

The three tasks

Everyone does Task 1: it is the skill you submit to the Skill Store. Then pick Task 2, Task 3 or both. Every task you finish scores.

T1
Bronze · required

Task 1: Robot routine

About 20 min100 pts+50 / 30 / 20 for the first three

Write a 20–30 second show for the dog.

⬆️Stand→ ➡️Walk→ 🔄Spin 360°→ 🤝Shake hand→ 💤Lie down

Requirements

  • At least: stand, one move (forward, back or sideways), one turn in place, one preset, then stop
  • Check known_presets() and skip moves this variant doesn't support, instead of crashing
  • Ctrl+C and exceptions trigger the e-stop (use the template)

Done when

It runs in dry-run, runs once on a real robot at a test station, and is submitted to the Skill Store. A mentor signs off. A web button panel that choreographs the moves earns +30.

Hint: the moves only

Run this from the starter repo's Task 1 template, which already uses graceful_shutdown.py. Don't run it on a real robot with a bare asyncio.run().

async def routine(dog):
    await dog.motion.stand()
    await asyncio.sleep(dog.motion.preset_timeout("stand"))
    await dog.motion.cmd_vel(linear=0.2)     # forward for 2 s
    await asyncio.sleep(2)
    await dog.motion.cmd_vel(angular=0.6)    # one turn left: 2π / 0.6 ≈ 10.5 s
    await asyncio.sleep(10.5)
    await dog.motion.stop()
    for name in ("shake_hand", "lie_down"):
        if name in dog.motion.known_presets():
            await dog.motion.do_preset(name)
            await asyncio.sleep(dog.motion.preset_timeout(name))

Requirements

  • A fist must stop the dog within 1 second. This is a safety item: fail it and the task scores zero
  • Watchdog: no hand seen for 0.5 s means stop()
  • Move at 0.3 m/s or slower

Done when

A mentor signals “stand → turn left → turn right → stop → shake hand” and the dog follows every step.

Hints

  • MediaPipe Hands gives you 21 landmarks per hand. Compare each fingertip with its base joint to tell whether the finger is straight
  • Run recognition and control as two asyncio tasks, so slow recognition never delays a stop
  • Real runs happen on the test station's Linux laptop and its camera. If the camera isn't available on site, this task becomes a web-remote cone race; rules on the night
T3
Gold

Task 3: Triangle back home

About 30 min300 pts+50 / 30 / 20 for the most accurate three

From a cross taped on the floor, walk an equilateral triangle with 1 m sides (forward 1 m, turn left 120°, three times) and stop back on the cross.

Requirements

  • Fully automatic: no human help once it starts
  • Linear speed 0.3 m/s or slower

Done when

A mentor measures from where the dog stops to the center of the cross. Within 50 cm counts. Ranked by error; ties go to the smaller heading error. A square or a five-pointed star on top earns +50.

Hints

  • Start open-loop. Time it: 0.25 m/s for 4 s is about 1 m; 0.6 rad/s for 3.5 s is about 120°. Floor slip adds up, so tune on site.
  • Go closed-loop to win. Use x, y and yaw from state.pose(): on straights, check distance covered; on turns, check the angle actually turned.
  • Print pose() once first and make sure it isn't NaN. Wrap angle differences into (−π, π]:
import math

def wrap(angle):
    return math.atan2(math.sin(angle), math.cos(angle))

# while turning: turned += wrap(yaw_now - yaw_last); stop() at 2π/3

FAQ

Can I team up?

Yes, pairs can work together on Tasks 2 and 3. Certificates are per person: everyone submits their own Task 1 and takes the exam.

I only have a Mac.

That works. There is no macOS wheel, so run the SDK in Docker: see Get set up. Build the image before the event if you can, since the base image is a download.

The health report says offline.

The native backend isn't loaded; it needs Linux and Python 3.10. Commands go out but the dog won't move. Ask a mentor.

The dog doesn't move.

Call stand() first: it has to stand before it can walk. Then check you've turned dry-run off.

A preset says “not supported”.

Footed and wheeled variants support different moves. Check known_presets() first.

A move gets cut off halfway.

After do_preset(), wait preset_timeout() seconds before sending the next command.

After an e-stop, every command is rejected.

Once it is safe, call dog.estop.reset(), then connect again.

pose() returns NaN.

There's no pose feedback right now. For Task 3, switch to timed open-loop control.

How do I get my code onto a test station?

Stations have no internet, so copy it over on a USB stick. Stations have spare sticks.

Which network do I use to publish and take the exam?
